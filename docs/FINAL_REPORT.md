# Итоговый отчёт

## 1. Что реализовано

- **Статический анализ** оригинального APK «Шлагбаум пульт гостевой доступ» 143.0 (`docs/ORIGINAL_APP_ANALYSIS.md`): стек, разрешения, экраны, backend (самостоятельный **Parse Server** + **FCM**), схема данных, и ключевой факт — удалённый звонок по push (`remotefcm`) в оригинале **уже есть**.
- **Сравнение трёх архитектур** и выбор (`docs/ARCHITECTURE_COMPARISON.md`): выбран **Вариант C** — минимальный управляемый backend с очередью команд как источником истины + доставка через FCM с резервным pull.
- **Backend** (`server/`): регистрация двух устройств, привязка по коду-приглашению, очередь команд, конечный автомат операции, идемпотентность, anti-replay, срок действия, отзыв, ограничение частоты, аудит без секретов, FCM-доставка (опционально) + резервный pull. Запускается локально; **20/20** авто-тестов + живой HTTP-прогон пройдены.
- **Android-приложение** (`android/`): одно приложение, две роли. Пульт (A) добавляет шлагбаум по коду, видит список, шлёт «Открыть» и наблюдает статус. Приёмник (B) хранит номер локально (allowlist), выдаёт доступ кодом, принимает команды (pull и/или FCM) и инициирует вызов через `TelecomManager.placeCall` из foreground-сервиса типа `phoneCall` (работает при заблокированном экране). По умолчанию — безопасный тестовый режим без реального звонка.
- **Документация**: установка на два телефона, сценарий теста на двух устройствах, разбор ограничений Android.

## 2. Выбранная архитектура и нужен ли сервер

**Вариант C (минимальный backend + push).** Сервер необходим: нужно проверять права (кто кому разрешил звонить), дедуплицировать команды, переживать офлайн приёмника, доставлять push адресно и хранить аудит. Прямое P2P-соединение на мобильных сетях за CGNAT это надёжно не закрывает. Очередь на сервере — источник истины; push ускоряет, pull гарантирует доставку после пробуждения. Обоснование совпадает с проверенным дизайном оригинала.

## 4. Команды сборки и путь к APK

```bash
cd android && chmod +x gradlew && ./gradlew :app:assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```
Либо через GitHub Actions (артефакт `shlagbaum-relay-debug-apk`). Подробности и ограничение среды — в `docs/INSTALL.md`.

## 5. Установка на два телефона

Кратко: поднять `server/`, собрать APK, установить на A и B, указать адрес сервера, выбрать роли, на B добавить шлагбаум и выдать код, на A погасить код и нажать «Открыть». Полная инструкция с настройками батареи/автозапуска — в `docs/INSTALL.md`.

## 7. Ограничения, требующие доработки

- **Сборка APK в этой среде невозможна** — заблокирован `dl.google.com` (Android SDK). APK собирается через GitHub Actions или локально.
- **Проверка звонка и фонового поведения** не выполнена — нет телефонов.
- **Надёжное пробуждение из глубокого Doze** требует включённого FCM (по умолчанию проект в режиме pull; FCM — опционально).
- **Совместимость со старым кодовым словом** оригинала невозможна без официального API/сотрудничества владельца (`vetver7@gmail.com`): логика кодовых слов закрыта на его сервере. В новой версии реализована своя модель приглашений.
- **OEM-ограничения** (Xiaomi/Huawei/…): нужны ручные настройки автозапуска/батареи на B.
- Хранилище — SQLite (прототип); для многих пользователей — Postgres.
- Нет end-to-end шифрования полезной нагрузки сверх TLS (можно добавить подпись команд, как намёк в оригинале через `key_pub2.pem`).

## 8. Следующие конкретные шаги до рабочего релиза

1. Собрать APK (GitHub Actions) и установить на два телефона.
2. Пройти сценарии 1–12 из `docs/TWO_DEVICE_TEST.md` в тестовом режиме, затем с реальным тестовым номером; заполнить таблицу результатов.
3. Включить FCM (раздел в `INSTALL.md`) и перепроверить сценарий выключенного на минуты экрана.
4. Развернуть backend на бесплатном хостинге с TLS; задать переменные окружения; проверить резервное поведение при сбое push.
5. Усилить безопасность: подпись команд, ротация токенов устройств, журнал без ПДн.
6. При желании сохранить старый сценарий кодового слова — запросить у владельца системы официальный API/описание Cloud-функций.
7. Доработать UX (диагностика связи, история операций, подсказки по настройкам OEM).
