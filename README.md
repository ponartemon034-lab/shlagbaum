# Шлагбаум Реле — прототип (новая версия с удалённым звонком через второй телефон)

Новая версия приложения для управления шлагбаумом: телефон A («пульт») удалённо заставляет телефон B («приёмник») позвонить на номер шлагбаума через интернет, в том числе при заблокированном экране B.

## Структура

- `docs/` — документация:
  - `ORIGINAL_APP_ANALYSIS.md` — анализ оригинального APK 143.0 (этап 1)
  - `ARCHITECTURE_COMPARISON.md` — сравнение 3 архитектур и выбор (этап 2)
  - `DEVICE_CALL_BACKGROUND.md` — звонок в фоне/при локскрине и ограничения Android (этап 4)
  - `INSTALL.md` — сборка и установка на два телефона
  - `TWO_DEVICE_TEST.md` — сценарий проверки на двух устройствах (этап 6)
  - `FINAL_REPORT.md` — итоговый отчёт
- `server/` — backend (Node.js, Вариант C): очередь команд + FCM/pull. Запускается и тестируется локально.
- `android/` — Android-приложение (Kotlin), роли «пульт» и «приёмник».

## Быстрый старт

```bash
# 1) backend
cd server && npm install --omit=optional && npm start      # :8080
# проверка логики:
DB_PATH=:memory: node src/selftest.js                      # 20/20

# 2) APK (нужен Android SDK — через GitHub Actions или локально; см. docs/INSTALL.md)
cd ../android && chmod +x gradlew && ./gradlew :app:assembleDebug
```

## Главное про безопасность и честность статусов

- Номер шлагбаума хранится только на телефоне B; в команде передаётся лишь метка `barRef`.
- B звонит только на номер из локального allowlist по авторизованной команде.
- По умолчанию — безопасный тестовый режим (звонок имитируется). Реальный звонок включается явно.
- «Вызов инициирован» ≠ «шлагбаум открыт» — приложение показывает именно статус вызова.
- Серверную авторизацию оригинала не обходим; секреты не извлекаем; серверные ключи в APK не кладём.

Подробности — в `docs/FINAL_REPORT.md`.
